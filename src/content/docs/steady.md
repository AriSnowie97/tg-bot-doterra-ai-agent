# Steady (заземлююча суміш)

**Категорія:** Ефірні Олії

**Тип:** Ефірна олія (з лінійки Kids Collection)

**Посилання:** https://www.doterra.com/US/en/p/

---

## Короткий опис

👑 Заземлююча суміш, розроблена спеціально для потреб дитячого тіла, розуму й емоцій. 
👑 Попередньо розведена у фракціонованій кокосовій олії для ніжної дії.

## Склад та ключові інгредієнти

▫️ Амірис
▫️ Бальзамічна ялиця
▫️ Коріандр
▫️ Магнолія
▫️ Фракціонована кокосова олія

## Показання

🔹 Для заземлення при перевантаженні
🔹 Для емоційної та розумової підтримки дитини

## Спосіб застосування

🔹 Має зручний формат флакона-ролика — легко застосовувати навіть маленьким дітям під наглядом дорослих.
🔹 Наносити на потрібні ділянки тіла за потреби.

## Сумісність з іншими продуктами doTERRA

🔹 doTERRA Kids Collection

## Цікаві факти

👑 Спеціально розроблено для дитячого віку
👑 Зручний формат ролера для безпечного самостійного використання дітьми під наглядом

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками.
> ⚠️ Уникати очей і чутливих ділянок шкіри дитини. Використовувати лише під наглядом дорослих.

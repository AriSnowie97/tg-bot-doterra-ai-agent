# dōTERRA Breathe® Touch

**Категорія:** Суміші (Blends)

**Тип:** Ефірна суміш Touch (рол-он, 10 мл)

**Посилання:** https://www.doterra.com/US/en/p/doterra-breathe-touch-essential-oil-blend

## Короткий опис

👑 Охолоджуюча, заспокійлива версія Breathe для легкого дихання
👑 Безпечна для застосування у всієї родини, включно з дітьми
👑 Зручний рол-он для швидкого застосування вдома чи в дорозі

▫️ Чайне дерево (Melaleuca)
▫️ Лимон

▫️ Равенсара

## Показання

🔹 Підтримка відчуття легкого дихання та чистих дихальних шляхів
🔹 Сезонні виклики довкілля
🔹 Створення атмосфери для спокійного сну

## Спосіб застосування

🔹 Нанести на груди, спину або підошви стоп, коли сезонні загрози високі
🔹 Використовувати на природі для мінімізації сезонних впливів
🔹 Масажувати груди чи стопи перед сном для спокійного відпочинку

## Сумісність з іншими продуктами doTERRA

🔹 dōTERRA Breathe® — класична (нерозведена) респіраторна суміш
🔹 dōTERRA Breathe® Vapor Stick, Drops та інші продукти лінійки

## Цікаві факти

👑 Попередньо розведений у фракціонованій кокосовій олії — м'який навіть для дитячої шкіри
👑 Евкаліпт та м'ята перцева мають високий вміст ментолу, що дає охолоджуючий ефект

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками. Уникайте прямого сонячного світла та УФ-променів протягом 12 годин після нанесення.

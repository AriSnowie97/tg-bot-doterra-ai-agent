# dōTERRA Serenity Softgels

**Тип:** supplement

---

## Короткий опис

👑 Капсули з лавандою та рослинними екстрактами для якісного відпочинку і розслаблення
👑 Заспокоює нервову систему і знижує рівень стресу без ефекту сонливості наступного дня
👑 Частина лінійки doTERRA Serenity для вечірнього ритуалу

---

## Склад та ключові інгредієнти

▫️ Ефірна олія лаванди (Lavandula angustifolia)
▫️ Рослинні екстракти для заспокоєння нервової системи (за рецептурою Serenity)
▫️ Капсула для внутрішнього вживання

---

## Способи застосування

🔹 1-2 капсули перед сном
🔹 Регулярне застосування для формування здорової звички засинання
🔹 Можна поєднувати з олією Serenity для дифузії у спальні

---

## Показання

👑 Якість сну: допомагає розслабитися перед сном
👑 Заспокоєння нервової системи: знижує рівень стресу
👑 Без ефекту млявості наступного ранку
👑 Вечірній ритуал: частина програми для здорового відпочинку

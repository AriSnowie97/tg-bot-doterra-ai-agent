# Adaptiv — Calming Blend

## Короткий опис

👑 Заспокійлива суміш, яка допомагає адаптуватися до нових обставин, стресу і напруги
👑 Солодкий, цитрусово-квітковий аромат (дикий апельсин, лаванда, копаіба, м'ята колосиста, магнолія, розмарин, нероль, амброве дерево)
👑 Поєднує заспокійливі й тонізуючі олії одночасно — для "спокійної бадьорості", а не сонливості

## Склад та ключові інгредієнти

▫️ Магнолія (Magnolia grandiflora)
▫️ Розмарин (Rosmarinus officinalis)
▫️ Нероль (Citrus aurantium)
▫️ Амброве дерево (Liquidambar styraciflua)

## Показання

🔹 Нове оточення чи ситуація: Допомагає адаптуватися при переїзді, новій роботі чи незнайомому місці
🔹 Важлива подія: Застосування перед іспитом, зустріччю чи виступом заспокоює нерви
🔹 Втома і неспокій: Балансує організм при відчутті втоми чи внутрішньої метушливості
🔹 Нерішучість і роздратованість: Допомагає знайти рівновагу при емоційній нестабільності

## Спосіб застосування

🔹 Дифузувати при переїзді, зміні роботи чи в незнайомому місці для адаптації, або під час медитації чи розслаблення
🔹 Змішати 3-4 краплі з сіллю Епсома і додати до ванни для розслаблюючого занурення; розвести базовою олією для заспокійливого масажу; нанести на зап'ястя чи шию (Touch-версія)
🔹 Ароматичні суміші для дифузора:
- Новий початок: 3 краплі Adaptiv
- Перед важливою подією: 3 краплі Adaptiv, 1 крапля дикого апельсина
- Заспокоєна концентрація: 3 краплі Adaptiv, 1 крапля розмарину
🔹 Внутрішній спосіб: Не рекомендовано для внутрішнього вживання олії — для харчової підтримки використовуються Adaptiv Calming Blend Capsules

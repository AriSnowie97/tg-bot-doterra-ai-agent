## Calmer

Тип: Ефірна олія (з лінійки Kids Collection)

### Короткий опис
👑 Заспокійлива суміш для сну, розроблена спеціально для потреб дитячого тіла, розуму й емоцій. 
👑 Попередньо розведена у фракціонованій кокосовій олії для ніжної дії.

### Вплив
▫️ Для спокійного засинання ввечері

### Спосіб застосування
🔹 Має зручний формат флакона-ролика — легко застосовувати навіть маленьким дітям під наглядом дорослих.

### Запобіжні заходи
🔹 Уникати очей і чутливих ділянок шкіри дитини. Використовувати лише під наглядом дорослих.

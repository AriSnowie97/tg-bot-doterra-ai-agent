# Calmer (заспокійлива суміш для сну)

**Категорія:** Ефірні Олії

**Тип:** Ефірна олія (з лінійки Kids Collection)

**Посилання:** https://www.doterra.com/US/en/p/тут-посилання-на-продукт

---

## Короткий опис

👑 Заспокійлива суміш для сну, розроблена спеціально для потреб дитячого тіла, розуму й емоцій. 
👑 Попередньо розведена у фракціонованій кокосовій олії для ніжної дії.

## Склад та ключові інгредієнти

▫️ Фракціонована кокосова олія
▫️ Компоненти заспокійливої суміші (відповідно до оригінального продукту)

## Показання

🔹 Для спокійного засинання ввечері

## Спосіб застосування

🔹 Має зручний формат флакона-ролика — легко застосовувати навіть маленьким дітям під наглядом дорослих.

## Сумісність з іншими продуктами doTERRA

🔹 Продукти з лінійки doTERRA Kids Collection

## Цікаві факти

👑 Належить до лінійки doTERRA Kids Collection
👑 Спеціально адаптована для дитячого віку

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками.
> ⚠️ Уникати очей і чутливих ділянок шкіри дитини. Використовувати лише під наглядом дорослих.

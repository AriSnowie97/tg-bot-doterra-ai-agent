# abōde Refreshing Blend

**Категорія:** Товари для дому

**Тип:** Ефірна суміш для дому (15 мл)

**Посилання:** https://www.doterra.com/US/en/p/abode-oil

---

## Короткий опис

👑 Фірмовий ароматичний бленд лінійки abōde для природного очищення дому
👑 Надає приємний свіжий аромат без токсичних компонентів
👑 Основа для всієї лінійки засобів для дому abōde

## Склад та ключові інгредієнти

▫️ Лайм (дистильований)
▫️ Літсея
▫️ Кассія
▫️ Евкаліпт лимонний
▫️ Чайне дерево
▫️ Арборвіте
▫️ Евкаліпт Кочії
▫️ Коріандр (листя)
▫️ Лавандин
▫️ Лемонграс / лимонний мирт

## Показання

🔹 Природне очищення поверхонь та повітря в домі
🔹 Усунення побутових запахів
🔹 Створення свіжої атмосфери в приміщенні

## Спосіб застосування

🔹 Дифузія: 3-4 краплі в дифузор
🔹 Додати 10-15 крапель у воду для нетоксичного спрею-очисника поверхонь
🔹 Кілька крапель на кульки для сушіння білизни для свіжого аромату
🔹 Топічно: 1-2 краплі на бажану ділянку, розбавивши базовою олією

## Сумісність з іншими продуктами doTERRA

🔹 abōde Surface Cleaner
🔹 Вся лінійка abōde (миючі засоби для дому)
🔹 Цитрусові й трав'яні олії — бергамот, дика помаранча, грейпфрут

## Цікаві факти

👑 Високий вміст лимонену, гераніалю, нералю та 1,8-цинеолу забезпечує потужні очищувальні властивості
👑 Евкаліпт Кочії з Західної Австралії має найвищу концентрацію 1,8-цинеолу серед усіх видів евкаліпту

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками. Уникайте прямого сонячного світла та УФ-променів протягом 12 годин після нанесення.

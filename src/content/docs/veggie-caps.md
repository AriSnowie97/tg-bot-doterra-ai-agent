# Veggie Caps

**Категорія:** БАДи

**Тип:** БАД (порожні рослинні капсули)

**Посилання:** https://www.doterra.com/US/en/pl/supplements-specialized

---

## Короткий опис

👑 Порожні рослинні капсули для самостійного приготування добавок з ефірними оліями
👑 160 капсул в упаковці — економний варіант для регулярного DIY-застосування
👑 Без сульфату лаурилу натрію, підходять для вегетаріанців

## Склад та ключові інгредієнти

▫️ Рослинна оболонка капсули (гідроксипропілметилцелюлоза)
▫️ Без наповнювача — капсула порожня, для самостійного заповнення

## Показання

🔹 DIY-застосування: дозволяє приймати улюблені ефірні олії внутрішньо в капсульованій формі, економія, контроль дозування, зручність (маскує смак)

## Спосіб застосування

🔹 Додати обрані краплі ефірної олії в капсулу, закрити і проковтнути із водою
🔹 Готувати капсулу безпосередньо перед застосуванням

## Сумісність з іншими продуктами doTERRA

🔹 Підходить для будь-яких ефірних олій doTERRA, безпечних для внутрішнього вживання (часто з орегано, чебрецем, лимоном тощо)

## Цікаві факти

👑 Формат дозволяє гнучко комбінувати кілька різних олій в одній капсулі
👑 Капсули підходять для вегетаріанців — виготовлені без желатину тваринного походження

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками.

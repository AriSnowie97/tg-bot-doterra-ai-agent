# Adaptiv Calming Blend Capsules

**Категорія:** БАДи

Посилання: https://www.doterra.com/US/en/p/adaptiv-oil-capsules

Тип: БАД (капсули для внутрішнього застосування)

#### Короткий опис

👑 Капсули для внутрішнього застосування на основі лаванди, коріандру, дикого апельсина і фенхелю

👑 Поєднує ефірні олії з клінічно дослідженими рослинними екстрактами (склеціум, ГАМК, ahiflower)

👑 Допомагає адаптуватися до стресових ситуацій і нових обставин

#### Склад та ключові інгредієнти

▫️ Ефірні олії: лаванда, коріандр, дикий апельсин, фенхель (рецептура для внутрішнього вживання, відмінна від олії Adaptiv)

▫️ Екстракт склеціуму (Sceletium, рослина канна з Південної Африки)

▫️ ГАМК (гамма-аміномасляна кислота)

▫️ Олія ahiflower — рослинне джерело омега жирних кислот

#### Показання

👑 Емоційний баланс: підтримує здорову емоційну реакцію на регулярні стресові фактори

👑 Спокій і ясність мислення: склеціум пов'язаний з відчуттям бадьорого спокою

👑 Розслаблення: ГАМК сприяє зниженню нервового збудження

👑 Адаптація: допомагає організму пристосуватися до нових обставин чи навантажень

#### Спосіб застосування

🔹 1 капсула на день для боротьби зі стресом, напругою і випадковою тривожністю

🔹 Капсули призначені саме для внутрішнього вживання — не плутати з олією Adaptiv для місцевого застосування чи дифузії

🔹 Регулярний прийом для найліпшого результату

#### Сумісність з іншими продуктами doTERRA

🔹 Можна поєднувати з олією Adaptiv для місцевого застосування чи дифузії протягом дня

🔹 Разом з Serenity Softgels для вечірнього розслаблення

#### Цікаві факти

👑 Склеціум (канна) — сукулентна рослина з Південної Африки, традиційно застосовується місцевими народами

👑 ГАМК іноді називають гальмами мозку — вона знижує активність нервових клітин

👑 Олія ahiflower — рослинне джерело омега жирних кислот з насіння рослини родини Boraginaceae

#### Запобіжні заходи

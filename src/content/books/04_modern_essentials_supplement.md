## 1. Корисна та безпечна частина: як застосовують олії

Це загальноосвітній матеріал, ризику в ньому немає:

- **Розпилення (дифузор):** випаровування через тепло/механіку; молекули олії досягають мозку за секунди, вплив на клітини організму — протягом ~2 годин (за даними буклету). Для початківців — починати з 1–2 крапель.
- **Нанесення на шкіру:** краплю на долоню, за потреби розвести базовою олією (кокосова фракціонована, жожоба, мигдальна) — олії не змішуються з водою, лише з ліпідами.
- **Ролери:** готові суміші на базовій олії у роликових флаконах — зручно для регулярного використання.
- **Масаж:** лише легкий/помірний тиск без спеціального навчання; масаж вагітних — не проводити без попереднього навчання.
- **Компрес:** крапля олії + теплий/холодний вологий рушник зверху.
- **Ванна:** олія не змішується з водою напряму — спочатку в сіль (епсомську/морську) або в базову олію чи емульгатор.
- **Кулінарія:** олії як заміна спеціям (1 крапля ≈ 1 ч. л. цедри/листя м'яти, 1 крапля ≈ 1 ст. л. кориці).
- **Рефлексологія стоп:** існує карта проекцій органів на стопи — використовується як доповнення до інших технік, не як самостійний метод лікування.

## 2. Система значків безпеки (легенда) — корисно для карток олій бота

| Значок (опис) | Значення |
|---|---|
| Можна використовувати в чистому вигляді | Не потребує розведення для дорослих зі здоровою шкірою |
| Може потребувати розведення для дитячої/чутливої шкіри | — |
| Рекомендується розведення | Завжди розводити перед нанесенням |
| Підходить для ароматичного використання (дифузор) | — |
| Уникати прямого вдихання розпилюваної олії | Подразнює при вдиханні напряму з дифузора без води |
| Безпечно для прийому всередину дорослими; дітям від 6 років — тільки розведене і в малих дозах; молодше 6 років — всередину не давати | Важливо для розділу «діти» в інтейку бота |
| Можна використовувати для прибирання | — |
| ☀️ Уникати сонця 12 годин після нанесення | Фототоксичність (цитрусові, деякі інші) |
| ☀️☀️ Уникати сонця 72 години після нанесення | Сильніша фототоксичність (наприклад, бергамот) |

Олії, відзначені в джерелі як подразливі при прямому вдиханні з дифузора: **гвоздика, кориця, орегано, чебрець**.

## 4. ⚠️ КРИТИЧНО ВАЖЛИВО: що не можна переносити в бота з цього джерела

На відміну від перших трьох книг, цей довідник побудований як алфавітний покажчик «назва хвороби → олія», і серед приблизно 150 пунктів є **прямі зіставлення олій із серйозними та потенційно смертельними станами**, включаючи:

- Епілепсія, судоми (епілептичний напад)
- Інсульт, аневризма, бічний аміотрофічний склероз (БАС), розсіяний склероз
- Хвороба Паркінсона, хвороба Альцгеймера, хвороба Хантінгтона
- Діабет, гіпо-/гіпертиреоз, зоб Хасімото, хвороба Грейвса, синдром Кушинга, хвороба Аддісона
- ВІЛ/СНІД
- Аутизм, СДУ/СДУГ
- Лейкемія, рак (у цих двох пунктах буклет сам відсилає до «повної книги», не дає протокол — але сам факт наявності пункту є неприпустимим для порадника)
- Мозкові травми, кома, струс мозку
- Стафілокок/MRSA, туберкульоз, малярія, кашлюк
- Укуси змій та павуків

**Чому це червоний прапор сам по собі:**
Це готовий шаблон «на кожну хворобу по олії», який прямо суперечить філософії безпеки бота в `03_intake_flow_and_routing.md`. Якщо такі записи потраплять у RAG як є, бот зможе відповісти людині з епілепсією чи інсультом рецептом на основі олії замість негайного направлення до лікаря.

**Жорстке правило:**
1. Жоден пункт зі списку вище не повинен потрапляти до бази знань бота у вигляді «рекомендації» чи «рецепту».
2. При згадці цих захворювань бот негайно зупиняє підбір і направляє до Наталії Котелянської та лікаря.

## 5. Легкі/побутові теми з цього джерела, безпечні для бази

Застуда, головний біль, м'язові болі та спазми, розтягнення, синці, опіки (легкі побутові), укуси комах, сезонні алергії, безсоння, тривога, стрес, печія/нетравлення, запор, нудота/заколисування, біль у вусі (лише зовнішнє нанесення навколо раковини, ніколи не капати у вушний канал), догляд за шкірою, акне, лупа, менструальний дискомфорт/ПМС, джетлаг, прибирання оселі.

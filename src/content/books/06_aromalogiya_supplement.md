# База знань: доповнення з книги «Аромалогія» (Світлана Миргородська)

**Джерело:** «Аромалогія», С. Миргородська — авторська праця з ароматерапії.
**⚠️ Авторське право:** опублікована авторська книга. Нижче структуровано адаптовані факти (правила дозування, протипоказання за оліями), а не прямі цитати.
**Значущість:** системний посібник, де протипоказання згруповані як за факторами ризику (вагітність, епілепсія, тиск, нирки), так і окремо для кожної олії. Слугує надійною базою для логіки безпеки бота.

---

## 1. Загальні правила дозування та безпеки

- **Формула дитячої дози:** 0,12 × середня доза за інструкцією × вік дитини (у роках), округлення за стандартними правилами. Приклад: 0,12 × 5 крапель × 3 роки ≈ 2 краплі.
- **Люди похилого віку та вагітні:** доза завжди вдвічі менша за середню дорослу.
- **Правило «21 день / перерва 7–14 днів»:** більшість олій не варто використовувати безперервно довше 3 тижнів, щоб уникнути звикання; після перерви дозу рекомендується дещо знизити.
- **Внутрішній прийом:** категорія підвищеного ризику, не більше кількох крапель на добу за наявності чітких показань, виключно у розведеному вигляді чи емульсії. Бот скеровує індивідуальні терапевтичні запити до Наталії Котелянської.
- **Суміші:** оптимально поєднувати 2–7 олій у побутових композиціях.
- **Тест на індивідуальну чутливість (3 дні):**
  - День 1 — вдихання з хустинки кілька разів на день.
  - День 2 — крапля розведеної олії (1:5 з базовою) на ділянку зап'ястя або ліктьового згину.
  - День 3 — тепла ванна з 1–2 краплями у солі, 5 хвилин.
  - Якщо за 3 дні немає подразнення очей, нежитю, висипань, почервоніння шкіри або нудоти — олія добре переноситься організмом.

## 2. Системні фактори ризику (за станом здоров'я)

| Фактор ризику | Олії під обмеженням / забороною |
|---|---|
| Епілепсія, схильність до судом | Більшість олій протипоказані. Умовно нейтральні: лаванда, апельсин, лимон. При епілепсії самостійний підбір суворо заборонено, обов'язкова консультація лікаря. |
| Схильність до судомних спазмів | Ісоп, розмарин, мускатний горіх |
| Вагітність (загальний підхід) | Див. позитивний перелік умовно дозволених олій нижче |
| Фототоксичність | Апельсин, грейпфрут, левзея, лимет, лимон, мандарин, петітгрейн, розмарин, чебрець — не наносити на відкриту шкіру мінімум за 12 годин до виходу на сонце |
| Подразнення слизової ШКТ | Аніс, бей, вербена, герань, материнка, жасмин, імбир, кедр, сосна, пачулі, пальмароза, ялиця, цитронела, чебрець — уникати натщесерце, тільки з олією чи йогуртом |
| Захворювання нирок | Ялина, жасмин (тільки зовнішньо), ялівець, ялиця, сандал |
| Порушення згортання крові / антикоагулянти | Аніс, базилік, ісоп, кипарис, герань, грушанка, береза |
| Гіпертонія високих ступенів | Бей, гвоздика, материнка, імбир, кориця, ялівець, мускатний горіх, розмарин, цитронела, чебрець, шавлія |
| Гіпотонія | Валеріана, жасмин |
| Безсоння (не застосовувати після 18:00) | Мускатний горіх, шавлія, цитронела, чебрець |
| Нервове виснаження | Гвоздика, кедр, кориця, мускатний горіх, цитронела, шавлія |
| Несумісно з алкоголем | Кедр, чебрець |
| Анемія / прийом препаратів заліза та йоду | Лаванда |
| Несумісно з гомеопатичними засобами | М'ята, ромашка |
| Діти до 7 років | М'ята (не наносити на шкіру обличчя та шиї) |
| Діти до 3 років | Чайне дерево — з особливою обережністю та високим розведенням |

## 3. Умовно дозволені олії при вагітності

Апельсин, бергамот, герань (обережно), жасмин (обережно), каяпут, лаванда (обережно), ладан (обережно), лимет, лимон, м'ята (обережно), найолі, неролі, петітгрейн, троянда, ромашка (обережно), сосна (обережно), чайне дерево, евкаліпт.
*Будь-яке застосування під час вагітності потребує схвалення провідного лікаря та Наталії Котелянської.*

## 4. Перша допомога при дискомфорті від олій

- **Олія потрапила в око:** промити чистим базовим рослинним маслом (не водою!), потім м'якою кип'яченою водою. Ефірні олії не розчиняються у воді.
- **Подразнення шкіри від олії:** нанести на ділянку чисту базову олію (наприклад, фракціоновану кокосову) у достатній кількості для розчинення та зняття концентрації.
- **Печія після прийому:** запити жирним кисломолочним напоєм або рослинним молоком.
- **Фотосенсибілізація (пігментна пляма від сонця):** м'які заспокійливі компреси, захист від ультрафіолету.
- **Золоте правило:** ефірні олії ліпофільні (розчиняються в жирах), вода лише підсилює їх проникнення крізь шкірний бар'єр.

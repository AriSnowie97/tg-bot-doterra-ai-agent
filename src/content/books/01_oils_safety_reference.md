# База знаний: эфирные масла — свойства, показания, противопоказания

**Источники:** «Ароматерапия для матери и ребёнка» (Э. Инглэнд, Л. Борг), «Сила в каждой капле» (doTERRA)
**Статус:** черновик для базы знаний бота «Аромы». Требует финальной проверки Натальей Котелянской перед публикацией — особенно раздел 4 (расхождение между источниками).
**Назначение:** источник фактов для RAG-поиска бота и для логики маршрутизации (см. `02_intake_flow_and_routing.md`).

---

## 1. Общие правила безопасности (применяются всегда, до подбора конкретного масла)

- **Беременность:** часть масел стимулирует менструацию/сокращения матки или считается слишком сильной для организма беременной. При беременности предпочтительна максимально низкая концентрация: **1% масляного раствора** (примерно вдвое меньше капель, чем в обычном рецепте), тогда как для остальных случаев ориентир — **2,5%**. Ниже приведены ориентировочные пропорции:
  - Обычная концентрация (не беременность): 100 мл базового масла → 50 капель эфирного; 50 мл → 25 капель; 10 мл → 5 капель.
  - Беременность / чувствительная кожа (≈1%): 100 мл → 25 капель; 50 мл → 12 капель; 10 мл → 2 капли.
- **Эпилепсия / повышенная судорожная готовность:** не использовать без согласования со специалистом; отдельно называются масла фенхеля, иссопа, шалфея (обычного), полыни и розмарина как повышающие риск.
- **Астма, экзема, дерматит, аллергии:** требуется предварительная консультация — реакция индивидуальна.
- **Дети до 3 месяцев:** эфирные масла в ванну не добавляются вообще (риск попадания в глаза при плохом размешивании). После 3 месяцев — только сильно разведёнными и по конкретным рецептам.
- **Общее правило разведения для детских смесей:** не превышать рецептурных пропорций; более концентрированные варианты не «эффективнее», а просто опаснее.
- Бергамот и другие цитрусовые (фототоксичность) — не наносить перед солнцем/загаром/солярием: риск неравномерной пигментации.
- Раздражающие слизистую масла, требующие особой осторожности при ингаляции/диффузоре: гвоздика, корица, лемонграсс, тимьян.
- Диффузор не рекомендуется располагать рядом с младенцами и беременными, пока конкретное масло не подтверждено как безопасное для этой ситуации.

## 2. Масла, которых следует избегать при беременности

(по данным книги «Ароматерапия для матери и ребёнка»; отдельные источники сокращают этот список до первого триместра, но автор рекомендует избегать на всём сроке)

Ангелика, анисовое семя, базилик, гвоздика, душица обыкновенная, жасмин (в чистом эфирном виде — не путать с местным применением в родах, см. профиль ниже), испанский майоран, иссоп, камфора, кедр, коричное дерево, любисток лекарственный, майоран, мелисса, мирра, можжевельник, мята перечная, петрушка, полынь эстрагон, розмарин, сладкий майоран, тимьян, фенхель обыкновенный, чабер, шалфей (обычный), шалфей мускатный.

Разрешены с оговорками:
- **Лаванда** — мягкая, можно использовать даже на ранних сроках.
- **Ромашка** (римская/немецкая) — разрешена, но прекратить при появлении необычных кровотечений.
- **Кипарис** — разрешён на поздних сроках, местно (например, при геморрое).

## 3. Масла, не рекомендованные к использованию в ароматерапии в принципе

(указаны как токсичные для этого способа применения — источник: та же книга; см. важное замечание в разделе 4 про Грушанку)

Аир, американский лавр, армоис, арника, горчица, горький миндаль, грушанка (wintergreen), кустарниковая полынь, лист бальдо, лист джаборанди, можжевельник казачий, мята болотная, пижма, полынь, рута, туя, хрен.

## 4. ⚠️ Расхождение между источниками — требует решения Натальи

Книга 1 (общая клиническая ароматерапия) включает **грушанку (wintergreen)** в список масел, которые нельзя использовать в принципе. При этом doTERRA (книга 2 и линейка продукции) официально продаёт грушанку как компонент обезболивающих смесей терапевтического класса (упоминается в «Сила в каждой капле», раздел «Облегчение боли»).

Это не ошибка распознавания — расхождение реальное и, вероятно, связано с разницей в стандартах чистоты/дозировке между обычным рынком эфирных масел (о котором пишет книга 1) и CPTG-стандартом doTERRA. **Бот не должен самостоятельно разрешать это противоречие** — по грушанке (и вообще при любом подобном конфликте источников) нужно жёстко маршрутизировать к Наталье, а не давать пользователю рекомендацию от лица бота.

## 7. Категории по темам (для интерфейса опроса бота)

Исходя из группировки книги 2, основной запрос пользователя логично делить на: **сон · боль/мышцы · пищеварение · иммунитет/простуда · кожа · дыхание · концентрация/энергия · эмоциональное состояние · дом (уборка) · дети · животные**. Дом и животные — не медицинская тема, можно отвечать сразу без скрининга противопоказаний.

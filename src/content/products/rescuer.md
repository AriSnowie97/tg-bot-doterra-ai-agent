# Rescuer (заспокійлива суміш)

**Категорія:** Ефірні Олії

**Тип:** Ефірна олія (з лінійки Kids Collection)


---

## Короткий опис

👑 Заспокійлива суміш, розроблена спеціально для потреб дитячого тіла, розуму й емоцій.
👑 Попередньо розведена у фракціонованій кокосовій олії для ніжної дії.

## Склад та ключові інгредієнти

▫️ Копайба
▫️ Лаванда
▫️ Колосиста м'ята
▫️ Зантоксилум

## Показання

🔹 Для заспокоєння дитячого тіла, розуму й емоцій
🔹 Для втомлених ніг чи м'язів після активного дня

## Спосіб застосування

🔹 Має зручний формат флакона-ролика — легко застосовувати навіть маленьким дітям під наглядом дорослих.

## Сумісність з іншими продуктами doTERRA

🔹 Належить до лінійки doTERRA Kids Collection

## Цікаві факти

👑 Розроблено спеціально для потреб дитячого організму

## Застереження

> ⚠️ Можлива чутливість шкіри. Зберігати в недоступному для дітей місці. Якщо ви вагітні, годуєте грудьми або перебуваєте під наглядом лікаря, проконсультуйтеся з ним. Уникайте контакту з очима, внутрішнім вухом та чутливими ділянками. Використовувати лише під наглядом дорослих.

## Додаткова інформація

- **Вплив:** Копайба, лаванда, колосиста м'ята, зантоксилум — для втомлених ніг чи м'язів після активного дня.

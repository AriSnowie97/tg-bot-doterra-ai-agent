# abōde Multi-Purpose Surface Cleaner Concentrate

**Категорія:** Товари для дому (abōde Line)

**Тип:** Концентрат багатоцільового засобу для прибирання


---

## Короткий опис

👑 Концентрат багатоцільового засобу для прибирання на основі ефірних олій — розводиться водою у власному флаконі
👑 Формула без фосфатів, сульфатів, фталатів, барвників і хлору
👑 Підходить для кухні, ванної кімнати, стільниць, плитки та лакованого дерева

## Склад та ключові інгредієнти

▫️ Ефірна суміш abōde Refreshing Blend: лайм, літсея, кассія, лимонний евкаліпт, чайне дерево, туя, кочійський евкаліпт, коріандр, лавандин, лимонний мирт
▫️ Тимол — ключовий компонент суміші, відомий очисними властивостями
▫️ Концентрована формула — знижує кількість пластику й транспортних витрат

## Показання

🔹 Універсальне прибирання: підходить для кухонних поверхонь, ванної кімнати, стільниць, сантехніки
🔹 Свіжий аромат: залишає приємний цитрусово-трав'яний запах у домі
🔹 Екологічність: концентрат зменшує використання пластику і транспортні викиди
🔹 Безпечніший склад: без фосфатів, сульфатів, фталатів, барвників і хлору

## Спосіб застосування

🔹 Залити концентрат у скляний флакон-розпилювач і долити чистою водою до позначки
🔹 Розпилити на поверхню і протерти чистою тканиною або губкою
🔹 Підходить для стільниць, кахлю, сантехніки, лакованого дерева; уникати необробленого каменю чи делікатних поверхонь без попередньої перевірки

## Сумісність з іншими продуктами doTERRA

🔹 Частина лінійки abōde — рідке мило для посуду, капсули для посудомийної та пральної машини, м'яч для сушарки
🔹 Аромат суміші abōde Refreshing Blend можна також використовувати окремо в дифузорі для освіження повітря

👑 Тимол, ключовий компонент суміші, широко відомий своїми очисними й антисептичними властивостями
👑 Суміш abōde Refreshing Blend відрізняється від суміші doTERRA On Guard — вона розроблена спеціально для прибирання дому, тоді як On Guard спочатку створювалася для внутрішнього застосування
👑 Продається як концентрат саме для того, аби зменшити транспортування зайвої води і скоротити вуглецевий слід
